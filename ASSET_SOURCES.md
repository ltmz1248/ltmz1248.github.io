# Game asset references

## Energy-sword like icon

- Local file: `dist/assets/halo/duelist-energy-sword.png`
- Asset: Duelist Energy Sword menu icon from Halo Infinite.
- Archive and provenance: [Halopedia file record](https://www.halopedia.org/File:HINF_DuelistEnergySword_Icon.png).
- Downloaded image: [Original image](https://halo.wiki.gallery/images/7/76/HINF_DuelistEnergySword_Icon.png).
- The file record identifies this as an icon extracted directly from the game's files and converted from linear to sRGB color space. It is a game asset hosted by a community archive, not a separately published 3D model download from the developer.
- Dimensions: 960 x 448, RGBA PNG.
- Download SHA-256: `c3ee8d4bbc76d23e3dbe71cc5583cf9ff538e257502e1cc5870b407bfdb4ce43`.
- The downloaded pixels are retained. CSS handles display size, dimming, and the brief like feedback.

## Hidden quote

The popup displays only: "Wake me. When you need me."

The wording is recorded in the [ending dialogue transcript](https://www.halopedia.org/Halo_%28Halo_3_level%29), and the line is also included in the official [Anniversary Angle: Quips & Quotes](https://www.halowaypoint.com/news/anniversary-angle-quips-quotes) article. The popup intentionally omits attribution.
